# Xiaomi 12T AOSP ROMs maintained by archcloudy
## Overview
This repo provides Xiaomi 12T OTA ROMs maintained by me (archcloudy), which you can find it on Releases.

There are two ROMs available:
- LineageOS (branch: `16.2` / `lineage-23.2`)
- PixelOS (branch: `sixteen-qpr2`)

For installation guide, see [Installation-Guide.md](/Installation-Guide.md).
